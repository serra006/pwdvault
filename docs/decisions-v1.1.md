# pwdvault v1.1 增量需求 — 已定决策（用户确认，不再讨论）

| 决策点 | 结论 | 约束 |
|---|---|---|
| UI 形态 | 本地 Web UI | 仅监听 127.0.0.1；主密钥只在 Python 进程，永不进浏览器 |
| 智能整理 | 复用 WorkBuddy 的 Agent | 应用不持有 API key、不直连大模型 API |
| 接入方式 | MCP Server (stdio) | WorkBuddy + deepseek-harness 通用，不得只适配一家 |
| 数据规模 | 几百条，单人 | 不做共享/多用户/权限 |
| 不可动摇的约束 | v1.0 的零知识性质 | 单文件 data.enc / 密钥不出本机 / 自由字段 / 原子写 / 快照 / 三种解锁 |

用户原话：
> 我希望更智能点，比如我以前保存的一个 TXT 文档丢进去，会自动调用 AGENT 帮我整理好，我需要的时候和 agent 说一句就能帮我复制出来，可以把这个应用接入 workbuddy 或者 dsh 这里。当然还需要个 UI 界面
