# pwdvault 怎么用

这份说明里的每一步都**在本机实测跑通过**（2026-10-23，用一个干净的临时库走完整流程）。

### 关于路径的两个约定

教程里会出现两种路径，别搞混：

| 写法 | 含义 | 你要不要改 |
|---|---|---|
| `<项目目录>` | 你把 pwdvault 放在哪，就填哪 | **要换成你自己的** |
| `C:\Users\...\python.exe` 这种具体路径 | 程序**自动探测**出来的你机器上真实存在的路径 | 不用改，直接用 |

第二种只出现在「复制给客户端的配置」里 —— 那是程序读你的环境生成的，不是写死的。
如果你想让配置里不出现任何本机路径，直接复制程序输出的那一块即可，不要手打。

## 一、主力是网页，不是命令行

| 你想做的事 | 用哪个 |
|---|---|
| **整理资料、增删改查、看清楚再入库** | **网页界面（主力）** |
| 手不想动，跟 AI 说一句就拿到密码 | MCP（接进 WorkBuddy / dsh） |
| 偶尔在终端里查一条 | 命令行（辅助，可选） |

命令行只在**第一次建库**时必要（那时还没有界面）。之后可以一直用网页。

三个入口操作同一个库文件，互不冲突。

---

## 二、第一次：建库（唯一必须用命令行的一步）

进到你的项目目录：

```bat
cd <项目目录>

:: 用管道给主密码（一行）。别写在命令行参数里 —— 会留在命令历史中
echo 你的主密码 | python pv.py init --password-stdin
```

会打印一段**恢复码**，形如 `SH6U-KUBH-...-32NZ`：

```
⚠ 请立刻用纸抄下来，或存到这个网盘之外的地方。
⚠ 忘了主密码时，它是唯一能打开数据的东西。
```

**只显示这一次。** 抄在纸上收好。

然后开本机免密 —— 这步很关键，网页和 AI 都靠它省事：

```bat
:: 注意 --password-stdin 的位置：必须在子命令**之前**
echo 你的主密码 | python pv.py --password-stdin local-unlock on
```

> **坑**：写成 `python pv.py local-unlock on --password-stdin` 会报
> 「非交互环境无法提示输入主密码」。全局参数要放在 `pv.py` 和子命令中间。

验证：

```bat
python pv.py local-unlock status
:: → 本机免密：已启用
```

从这一步之后，**就可以一直用网页了**。

## 三、日常：网页界面

```bat
python pv.py web
```

自动开浏览器，只监听 `127.0.0.1`（别的机器连不上）。

常用参数：

```bat
python pv.py web --no-browser          :: 不开浏览器，自己访问打印出来的地址
python pv.py web --port 9000           :: 指定端口（被占用会自动顺延）
```

### 解锁

开了本机免密，界面上直接点**「用这台电脑直接进入」**。也可以用主密码或恢复码解锁。

> 界面上那句提示是准的：**在网页解锁不会让 AI 那边也能用**。
> Web 和 MCP 是两个独立进程，各有各的密钥。AI 要能自己解锁靠的是
> `pv local-unlock on`，不是「我在界面上解锁过」。

### 界面能做什么

- 搜索（`/` 聚焦）、按标签筛选
- 新增 / 编辑 / 删除记录
- 复制密码（默认 30 秒后自动清空剪贴板）
- 显示明文（点「显示」，15 秒后自动收回）
- **待整理**页：批量处理 inbox 收上来的资料（见下一节）
- **健康检查**页：弱密码、重复密码、长期未改、备份状态
- **设置**页：复制 MCP 接入配置

## 四、把一堆旧资料整理进库（核心场景）

假设你有个 `我的资料.txt`：

```
淘宝
账号: zhangsan@example.com
密码: Tb#2024xyZ
网址: https://taobao.com

知乎
账号: lisi
密码: Zhi!hu2024

我的密钥
AccessKey: AKIA-DEMO-KEY-1234
备注: 服务器用
```

### 1. 丢进 inbox

`inbox` 目录在库文件旁边。把文件放进去就行。
也可以在网页「待整理」页直接拖进去。

### 2. 等 2 秒，自动出现

实测：文件丢进去后 **2 秒内**被扫到，自动解析成 3 条：

```
淘宝      账号 zhangsan@example.com   网址 https://taobao.com
知乎      账号 lisi
我的密钥                              备注「服务器用」  自定义字段 AccessKey
```

- 密码栏显示 `••••` —— **网页默认不显示明文**
- `AccessKey: AKIA-...` 这种不认识的键会**原样存进自定义字段**，不会被丢掉。
  这就是「自由字段」的意思。

### 3. 逐条看，改，勾掉不要的

每条都能编辑。密码框留空就表示「不改」。

### 4. 提交入库

底部条有「重复时：跳过 / 覆盖 / 新建副本」。默认**跳过**（已存在的不动）。
点「提交 N 条」。

入库后想反悔，「待整理」页有**撤销这批入库**。

## 五、让 AI 帮你取密码（MCP）

### 1. 拿配置

网页「设置」页有一块「接入」，点**复制**。程序已经把你的 python 路径、
pv.py 路径、库路径都填好了 —— 直接粘贴，不要手改。

### 2. 粘贴进客户端

- **WorkBuddy**：`~/.workbuddy/mcp.json` 的 `mcpServers` 里
  → 连接器管理页右上角「自定义连接器」点**信任** → **重启客户端**
- **deepseek-harness**：`~/.deepseek/config.json` 的 `mcpServers` 段

看到 `vault_*` 开头 **10 个工具**就算接上了。

> 如果你要手填：`args` 是**两项** —— pv.py 的绝对路径 + 子命令 `mcp`。
> 写成只有 `["mcp"]` 会变成 `python mcp`（把 mcp 当文件名打开），必失败。

### 3. 说话就行

工具参数是 `query`，**不需要你知道记录 id**。实测：

| 你说 | AI 调用 | 结果 |
|---|---|---|
| 「帮我把淘宝的密码复制出来」 | `vault_copy(query="淘宝")` | 密码进剪贴板，30 秒后自动清空 |
| 「拿一下密钥的 AccessKey」 | `vault_copy(query="密钥", field="AccessKey")` | 同上 |
| 「知乎的账号是多少」 | `vault_get(query="知乎")` | 返回账号；密码是 `••••` |

**密码永远不进对话**：`vault_search` / `vault_get` 只返回 `has_password: true`
这种「有没有」，不返回值。`vault_copy` 只回一句回执，明文只存在于剪贴板里。

10 个工具：

```
vault_status          vault_search          vault_get          vault_copy     vault_totp
vault_staging_list    vault_staging_claim   vault_staging_submit
vault_add             vault_update
```

> **注意：AI 没有落库权限。** `vault_staging_commit` 这类工具不存在，
> 批量整理的最后一步（入库）必须由你在界面上确认。这是有意的。

## 六、命令行（辅助，可选）

```bat
python pv.py find 淘宝              :: 模糊搜索
python pv.py find tag:购物          :: 按字段搜（tag / user / title）
python pv.py copy <id>              :: 密码进剪贴板，30 秒后清空
python pv.py copy <id> --field 手机号
python pv.py totp <id>              :: 动态验证码
python pv.py list                   :: 列出全部（不含密码）
python pv.py show <id> --reveal     :: 看明文（别把输出贴到聊天里）
python pv.py doctor                 :: 体检 + 备份检查
```

给主密码的三种方式（非交互时必选其一）：

```bat
set PV_MASTER_PASSWORD=你的密码                     :: 1. 环境变量
echo 密码 | python pv.py --password-stdin find 淘宝  :: 2. 管道
python pv.py local-unlock on                        :: 3. 本机免密（推荐）
```

## 七、把库放进网盘

程序**不接任何网盘 API**。你只要把 `data.enc` 放进同步目录：

```bat
python pv.py --vault "C:\Users\你\OneDrive\pwdvault\data.enc" init
:: 或者固定下来
set PV_VAULT=C:\Users\你\OneDrive\pwdvault\data.enc
```

同目录的 `snapshots/` 会一起同步 —— 这是有意的：网盘上的历史版本能救「改错了」。

## 八、出事了怎么办

| 现象 | 处理 |
|---|---|
| 忘了主密码 | `set PV_RECOVERY_CODE=纸上的码`，能读能改，然后 `pv passwd` 换新密码 |
| 提示「口令错误或文件已被篡改」 | 这两者**无法区分**。先确认密码，再 `pv doctor` 看文件大小是否正常 |
| 改错了 / 误删 | `pv doctor` 找快照目录，复制最新的覆盖 `data.enc` |
| 网盘出现 `data (1).enc` | `pv doctor` 比较修订号，留大的那个 |

## 九、几个已经验证过的行为（省得你猜）

**剪贴板自动清空**，实测四条路径：

| 路径 | 30 秒后是否清空 |
|---|---|
| `pv copy`（命令行） | ✅ 会（起一个独立守护进程计时） |
| 网页界面点「复制」 | ✅ 会（网页是长驻进程，进程内定时器） |
| AI 取密码（MCP 常驻，如接在 WorkBuddy 里） | ✅ 会 |
| MCP 被一次性调用、用完立刻退出 | ❌ 不会 —— 定时器随进程消失 |

最后一条只在「客户端每次调用后重启 MCP 进程」时才出现。正常客户端都是常驻的，
**实测常驻方式下 33 秒后剪贴板确认为空**。如果你用的客户端是短命模式，
用完记得手动复制点别的东西覆盖掉剪贴板。

**安全上的硬保证：**

- 网页只监听 `127.0.0.1`，外部机器连不上
- 每次启动换一个新 token，带 Host 校验（防 DNS rebinding）和跨站拒绝
- 响应里密码一律 `••••`，要看明文是一次性动作，15 秒后收回
- 谁在什么时候读了哪个字段，都记在 `logs/audit.jsonl`（只记字段**名**，不记值）
- 导出明文（`pv export`）是唯一绕过上述保护的命令，它会被审计，
  并往 **stderr** 打「这是明文文件，用完立刻删除」

## 十、还没做完 / 已知边界

1. **审计页**（界面上看审计日志）还没做，日志只能直接看 `logs/audit.jsonl`。
2. 界面上的「打开 inbox / 库目录 / 快照目录」目前是**复制路径**，不会真打开资源管理器
   （浏览器不能跳 `file://`，真要打开得后端加接口）。
3. 界面里**不能改自定义字段的值**（只能看字段名），改请用 `pv edit`；
   待整理页里可以改。
4. 改主密码、自锁分钟数、剪贴板秒数、inbox 目录与监听开关 —— 这些设置项
   界面上是**只读**的，要改得动 `config.toml` 或用命令行。
5. 列表分批渲染（每批 80 行 + 滚动续取），几百条很顺，几千条会明显变慢。
6. 丢弃过一个批次之后，同一个文件从 inbox 扫进来不会再建批（有意的：
   防止丢掉的东西每 2 秒回来一次）。真想再处理，改一下文件内容使其 sha256 变化，
   就会被认成新文件。
