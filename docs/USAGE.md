# pwdvault 怎么用

**整篇没有一步是必须敲命令行的。** 从双击开始，到整理资料、改设置、导出备份，
全在浏览器里点。命令行被降级到了最后一张附录 —— 日常使用你不需要看那一章。

这份说明里的每一步都**在本机实测跑通过**（2026-10-23，用一个干净的临时库走完整流程）。

### 关于路径的两个约定

| 写法 | 含义 | 你要不要改 |
|---|---|---|
| `<项目目录>` | 你把 pwdvault 放在哪，就填哪（比如 `D:\tools\pwdvault`） | **要换成你自己的** |
| `%USERPROFILE%\pwdvault` | Windows 通用写法，等于「你自己的用户目录下的 pwdvault」 | 不用改，系统自己认 |

本文档不会出现任何具体机器上的路径。要找你的库文件在哪，打开界面**设置 → 维护**，
那里会把你机器上的真实路径列出来。

## 一、双击就能用

项目根目录里有两个启动器，**挑一个双击就行，不用都双击**：

| 文件 | 双击后的样子 | 适合谁 |
|---|---|---|
| `start-pwdvault.bat` | 会弹一个黑色命令行窗口，里面滚动日志 | 想看见它有没有在正常跑的人 |
| `start-pwdvault.vbs` | **没有任何窗口**，只有浏览器被打开 | 不想被黑窗口打扰的人 |

两个干的事完全一样：起本地服务 → 自动打开浏览器 → 你在网页里操作。

之后会看到浏览器打开一个 `http://127.0.0.1:8765/...` 的地址。

**怎么停：** `.bat` 关掉那个黑窗口就行（或在里面按 Ctrl+C）；`.vbs` 去任务管理器
里结束 `python.exe`。停不停其实无所谓 —— 它只监听 `127.0.0.1`，别的机器连不上，
放着跑一天也没事。

### 几个可能遇到的小状况

| 现象 | 怎么办 |
|---|---|
| 双击后黑窗口一闪就没了 | 窗口里那几行字就是原因。最常见的是没装 Python |
| 提示「没找到 Python」 | 装 Python 3.10 以上，**安装时勾选 Add python.exe to PATH**，装完重新双击 |
| 浏览器没自动打开 | 看黑窗口里打印的那行地址，手动粘到浏览器。`.vbs` 没窗口的话，端口固定是 8765 |
| 8765 被别的软件占了 | 它会自动顺延到 8766、8767……以窗口里打印的那一行为准 |
| 双击后什么都没发生，也没报错 | 可能是系统把脚本拦了：右键文件 → 属性 → 勾「解除锁定」 |

> 端口、令牌这些细节都不用你操心。每次启动会换一个新的一次性 token，
> 界面地址里带着它，别人拿到旧地址也进不去。

## 二、第一次打开：创建密码库

第一次打开时，界面上会直接是**建库向导**（因为那个位置还没有库）。

### 1. 主密码怎么选

向导会让你输入两遍主密码，边打字边提示强度（强度由服务端按同一套算法算，
网页不自己瞎估）。

**主密码不存在任何地方** —— 没有「找回密码」，也没有服务器帮你记。忘了它，
就只剩恢复码这一条路。所以：

- **用一句话，不要用一串字符。** 5 个以上随机词最划算，好记又抗暴力破解：
  「橘子 铁路 钢琴 沙漠 灯塔」、`correct horse battery staple`
- **别用** 生日+名字、手机号、`Password123`、任何你在别处用过的密码
- 文件会放到网盘上，意味着攻击者可以**离线无限次尝试**。6 位数字几秒钟就破，
  上面那种五个词的组合按现在的算力基本没戏

太弱的密码会被直接拦下来（强度是服务端算的，网页不自作主张）。
真想用那个密码，对话框里有个「我知道风险」的勾 —— 勾上就能过，但后果自负。

下面是「库名称（可选）」，留空就叫 pwdvault。

### 2. 本机免密 —— 勾着就行

默认**已经勾选**了「启用本机免密（在这台电脑上不用输主密码）」。
勾着它，以后打开界面直接进，不用每次输主密码；后面让 AI 帮你取密码也靠它。**默认就好。**

它靠 Windows 的 DPAPI 把密钥绑在你的**用户身份**上。意思是：防「文件被拷走」，
不防「这台电脑已经中招」。主密码的包裹永远保留，免密只是便利层。
不放心就到**设置**页关掉。

### 3. 抄下恢复码

点「创建密码库」后，会跳到**抄下你的恢复码**这一页：

```
形如 JBSW-Y3DP-EHPK-3PXP-...  一共 8 组，可以直接点「复制」
```

三条警告，一条都别当耳旁风：

1. **立刻用纸抄下来** —— 只截图、只存文件，都不算备份
2. 忘了主密码时，它是**唯一**能打开这份数据的东西
3. **不要和库文件放在同一个网盘里**（一个地方被端就全没了）

**这个码只显示这一次**，关掉就再也取不回来了。所以那一页有个
「我已抄下恢复码」的勾，**不勾，「进入密码库」按钮是灰的** —— 这是故意卡你一下的。

## 三、日常使用

### 解锁

打开界面后三种进法：

- **用这台电脑直接进入** —— 开了本机免密就有这个按钮，点一下就进
- **输主密码** —— 常规方式
- **用恢复码解锁** —— 折叠在下面，忘了主密码时走这条

> 界面上那句提示是准的：**在网页解锁不会让 AI 那边也能用。**
> 网页和 MCP 是两个独立进程，各有各的密钥。AI 要能自己解锁，靠的是设置页里的
> 本机免密开关，不是「我在界面上解锁过」。

右上角有**锁定**按钮，还有个倒计时 —— 到点自动锁。

### 找东西

| 想干啥 | 怎么操作 |
|---|---|
| 搜索 | `Ctrl+K` 直接聚焦搜索框 |
| 翻列表 | `↑` `↓` 移动 |
| 复制当前这条的密码 | 在列表上按 `Enter` |
| 改标题 | 在列表上按 `Ctrl+Enter` |
| 清空搜索 | `Esc` |
| 按标签筛 | 左栏「标签」区点一个 |
| 按状态筛 | 左栏「视图」：全部 / 最近使用 / 无密码 / 有 TOTP |

### 增删改

- **新增**：左栏底部「+ 新建记录」
- **改**：详情页右上「编辑」。标题可以直接双击改
- **删**：详情页右上「删除」（会让你确认）

### 复制密码

详情页右上「复制密码」「复制账号」，密码默认是 `••••`。

**复制之后 30 秒，剪贴板会被自动清空** —— 不用你自己去复制点别的东西盖掉。
想看不复制，点「显示」，15 秒后会自动收回成 `••••`。

### 动态验证码（TOTP）

记录里存了 TOTP 密钥的话，详情页会多一行「动态码」，右边标着 `TOTP`。
点「查看」显示 6 位数字和剩余秒数，到点自动刷新。

### 健康检查页

左栏底部「健康检查」，会告诉你：弱密码、重复密码、超过一年没改的、
还没备份的。**只看统计和标题，密码本来就看不到。**

## 四、把一堆旧资料整理进库（核心场景）

这是本项目最有用的地方：手上有一堆乱七八糟的账号密码文本？不用一条条手工录。

假设你有个 `我的资料.txt`：

```
淘宝
账号: zhangsan@example.com
密码: Tb#2024xyZ
网址: https://taobao.com

知乎
账号: lisi
密码: Zhi!hu2024

我的密钥
AccessKey: AKIA-DEMO-KEY-1234
备注: 服务器用
```

### 1. 丢进来（三种方式，任选）

- **拖**：左栏底部「待整理」页，把文件直接拖进那个虚线框
- **选**：点框里的「选择文件…」
- **放**：直接把文件拷进 inbox 文件夹（点「打开 inbox 文件夹」会**把路径复制下来**，
  粘到资源管理器地址栏回车；默认在 `%USERPROFILE%\pwdvault\inbox`）

支持 `.txt` `.csv` `.json` `.md` `.log` `.tsv`。

### 2. 等 2 秒，自动出现

实测：文件丢进去后 **2 秒内**被扫到，自动解析成 3 条：

```
淘宝      账号 zhangsan@example.com   网址 https://taobao.com
知乎      账号 lisi
我的密钥                              备注「服务器用」  自定义字段 AccessKey
```

- 密码栏显示 `••••` —— **网页默认不显示明文**
- `AccessKey: AKIA-...` 这种不认识的键会**原样存进自定义字段**，不会被丢掉。
  这就是「自由字段」的意思

### 3. 逐条看，改，勾掉不要的

左边是批次列表，右边是这一批里的条目。每条都能改：
密码框**留空就表示「不改」**。不想入库的，把它的勾去掉。

右上角有「全选」，底下显示「已接受 N / M 条」。

### 4. 遇到重复的怎么办

底部条上有个「重复时」，三个选项，**只对这一批生效，不会写进配置**：

| 选项 | 行为 |
|---|---|
| **跳过**（默认） | 库里已经有「标题+账号」一样的，就**不动它** |
| 覆盖 | 用新的把旧的更新掉 |
| 新建副本 | 一律新增，库里会有两条同名的 |

默认是跳过 —— 也就是**已经存在的不动**，这是最不容易出事的那个。

### 5. 提交

点「提交 N 条」就入库了。

**入库后想反悔：** 底部条上有「撤销这批入库」，整批撤回来。
整个批次都不想要了，点「丢弃整个批次」。

## 五、设置页能做的事

左栏底部「设置」。分能做和只能看两类 —— **只能看**的那些要改 `config.toml`，
或者直接看附录的命令行。

### 能直接操作的

| 操作 | 在哪 | 注意 |
|---|---|---|
| **改主密码** | 安全 → 改主密码 | 只重包密钥，不重加密全部数据，很快。用主密码进来的要再输一次当前密码；用免密或恢复码进来的不用 |
| **重新生成恢复码** | 安全 → 重新生成恢复码 | **旧码立刻失效**，新码照样只显示一次 |
| **本机免密开关** | 安全 → 本机免密 | 开了之后这台电脑不用输主密码，AI 那边也靠它 |
| **导出明文** | 危险区 → 导出明文… | **全产品唯一能一次性把所有密码写成明文的动作**。会被记进审计日志。用完立刻删 |
| **复制 MCP 配置** | 接入 Agent（MCP） | 见下一章 |

前两个会重写库头部的加密参数。拍板之前，先去「维护」那节确认快照目录里有份
能用的旧文件。

### 只能看（要改就动 `config.toml`）

自动锁定时间、剪贴板清空秒数、inbox 目录与监听状态、当前解锁方式。

### 维护

这里会列出你机器上的**真实路径**：库目录、快照目录、服务地址。
「打开库目录」「打开快照目录」两个按钮目前是**把路径复制到剪贴板**，
不会真的弹出资源管理器（浏览器不许跳 `file://`）。粘到资源管理器地址栏回车即可。

## 六、让 AI 帮你取密码（MCP）

这一章唯一要动手的地方，是在 **AI 客户端**里贴一段 JSON ——
那不是本项目的命令行，是 Claude Desktop / Cursor / WorkBuddy 这类客户端自己的
配置文件。你只是**打开它的配置文件，把东西粘进去**，不是在终端里敲命令。

### 1. 复制配置

设置页「接入 Agent（MCP）」那一节，配置是**服务端按你的环境生成好的**
（python 路径、pv.py 路径、库路径都填好了）。点复制，整段拿走。

> `command` / `args` / `env` 三个键必须**整段照抄**。自己拼参数会让客户端启动失败，
> 而它只会显示「零个工具」，你根本看不出是哪里错了。

### 2. 粘进客户端

| 客户端 | 配置文件位置 |
|---|---|
| WorkBuddy | `~/.workbuddy/mcp.json` 的 `mcpServers` 段 |
| Claude Desktop | `claude_desktop_config.json` 的 `mcpServers` 段 |
| deepseek-harness | `~/.deepseek/config.json` 的 `mcpServers` 段 |

粘完**重启客户端**（这一步最容易忘，不重启不会生效）。
WorkBuddy 还需要在连接器管理页右上角「自定义连接器」点一下**信任**。

看到 `vault_*` 开头 **10 个工具**就算接上了。

**前提：** AI 要能自己解锁，得先开着本机免密（设置页里有开关）。
不然 AI 每次都得问你要主密码 —— 而它问不了，因为它的 stdin 被协议占用了。

### 3. 说话就行

工具参数是 `query`，**不需要你知道记录 id**。实测：

| 你说 | AI 调用 | 结果 |
|---|---|---|
| 「帮我把淘宝的密码复制出来」 | `vault_copy(query="淘宝")` | 密码进剪贴板，30 秒后自动清空 |
| 「拿一下密钥的 AccessKey」 | `vault_copy(query="密钥", field="AccessKey")` | 同上 |
| 「知乎的账号是多少」 | `vault_get(query="知乎")` | 返回账号；密码是 `••••` |

**密码永远不进对话：** `vault_search` / `vault_get` 只返回 `has_password: true`
这种「有没有」，不返回值。`vault_copy` 只回一句回执，明文只存在于剪贴板里。

10 个工具：

```
vault_status          vault_search          vault_get          vault_copy     vault_totp
vault_staging_list    vault_staging_claim   vault_staging_submit
vault_add             vault_update
```

> **注意：AI 没有落库权限。** `vault_staging_commit` 这类工具**故意不存在** ——
> 批量整理的最后一步（入库）必须由你在界面上点。

## 七、把库放进网盘

程序**不接任何网盘 API**，也不认识 OneDrive / 坚果云。你只要把库文件放进同步目录，
剩下的交给网盘客户端。

**先找到库文件在哪：** 设置页「维护」那节会列出库目录，默认在
`%USERPROFILE%\pwdvault`，里面的 `data.enc` 就是库。

**搬到网盘的两种方式：**

1. 去 `config.toml` 里改 `vault.path`，指到网盘目录里的 `data.enc`
2. 或者设一个 `PV_VAULT` 环境变量指过去

（改完要重启服务。网盘路径怎么填，看你自己想把库放哪。）

搬过去之后，把整个目录都同步 —— **尤其是 `snapshots/`，这是有意的**：
网盘上的历史版本能救「改错了」。

**同步的三条注意：**

1. **别在两台电脑上同时开着服务改同一个库。** 本项目有跨进程锁，但网盘是异步的，
   两台机器各写各的，最后必然冲突
2. 只有你一个人用、每次都是整体原子覆盖，冲突概率其实很低
3. 万一网盘吐出 `data (1).enc` 这种冲突副本，用健康检查页或直接比较文件，
   **留修订号大的那个**

## 八、出事了怎么办

| 现象 | 处理 |
|---|---|
| **忘了主密码** | 解锁页底下「用恢复码解锁」，填上纸上的码 → 进去后**立刻去设置页改一个新主密码** |
| 主密码和恢复码**都没了** | 只能从 `snapshots/` 里挑一个旧文件回滚 —— 而且还得记得那会儿用的密码。所以第 2 章那张纸很重要 |
| 提示「口令错误或文件已被篡改」 | 这两者**无法区分**。先确认密码输对了，再看文件大小是否正常 |
| 改错了 / 误删 | 去快照目录，把最新的那个复制成 `data.enc` |
| 网盘出现 `data (1).enc` | 比较修订号，留大的那个 |
| 刚整理入库的一批不对 | 待整理页 →「撤销这批入库」，整批撤回来 |

## 九、几个已经验证过的行为（省得你猜）

**剪贴板自动清空**，实测四条路径：

| 路径 | 30 秒后是否清空 |
|---|---|
| 网页界面点「复制」 | ✅ 会（网页是长驻进程，进程内定时器） |
| AI 取密码（MCP 常驻，如接在 WorkBuddy 里） | ✅ 会 |
| 命令行 `pv copy` | ✅ 会（起一个独立守护进程计时） |
| MCP 被一次性调用、用完立刻退出 | ❌ 不会 —— 定时器随进程消失 |

最后一条只在「客户端每次调用后重启 MCP 进程」时才出现。正常客户端都是常驻的，
**实测常驻方式下 33 秒后剪贴板确认为空**。如果你用的客户端是短命模式，
用完记得手动复制点别的东西盖掉。

**安全上的硬保证：**

- 网页只监听 `127.0.0.1`，外部机器连不上
- 每次启动换一个新 token，带 Host 校验（防 DNS rebinding）和跨站拒绝
- 响应里密码一律 `••••`，要看明文是一次性动作，15 秒后收回
- 谁在什么时候读了哪个字段，都记在 `logs/audit.jsonl`（只记字段**名**，不记值）
- 导出明文是唯一绕过上述保护的动作，它会被审计，并明确警告你用完立刻删

**已知边界（还没做完的）：**

1. **审计页**还没做，日志只能直接看 `logs/audit.jsonl`
2. 界面上的「打开 inbox / 库目录 / 快照目录」是**复制路径**，不会真打开资源管理器
3. 自锁分钟数、剪贴板秒数、inbox 目录 —— 这些设置项界面上是**只读**的，
   要改得动 `config.toml`
4. 列表分批渲染（每批 80 行 + 滚动续取），几百条很顺，几千条会明显变慢
5. 丢弃过一个批次之后，同一个文件从 inbox 扫进来不会再建批（**有意的**：
   防止丢掉的东西每 2 秒回来一次）。真想再处理，改一下文件内容让它 sha256 变化，
   就会被认成新文件

## 十、附录：命令行（高级用户可选）

> **日常使用完全不需要这一章。** 前面九章覆盖了建库、日常、整理、设置、备份、
> 救急的全部操作，都在浏览器里点。这里是给想写脚本、想排障、或者界面还没做到
> 那一步的人留的。

### 怎么用

在 `<项目目录>` 里，用这个形式（不用写死 python 路径，系统自己认）：

```bat
python pv.py <子命令>
```

比如：

```bat
python pv.py find 淘宝              :: 模糊搜索
python pv.py find tag:购物          :: 按字段搜（tag / user / title）
python pv.py copy <id>              :: 密码进剪贴板，30 秒后清空
python pv.py copy <id> --field 手机号
python pv.py totp <id>              :: 动态验证码
python pv.py list                   :: 列出全部（不含密码）
python pv.py show <id> --reveal     :: 看明文（别把输出贴到聊天里）
python pv.py doctor                 :: 体检 + 备份检查
python pv.py web                    :: 就是启动器双击后跑的那条
```

主密码的三种给法（非交互时必选其一）：

```bat
set PV_MASTER_PASSWORD=你的密码                      :: 1. 环境变量
echo 密码 | python pv.py --password-stdin find 淘宝   :: 2. 管道
python pv.py local-unlock on                          :: 3. 本机免密（推荐）
```

> **坑**：`--password-stdin` 是**全局参数**，得放在 `pv.py` 和子命令**中间**。
> 写成 `python pv.py find 淘宝 --password-stdin` 会报「非交互环境无法提示输入主密码」。

### 为什么还留着 `pv mcp`

`pv mcp` 不是给你敲的 —— 它是 AI 客户端在后台帮你跑的那条命令。
第六章让你粘进客户端的那段 JSON 里，`args` 就是指向它的。
所以即使你从不敲命令行，这个子命令也得在：

```
客户端启动 → 后台跑 `python pv.py mcp` → 走 stdio 说 JSON-RPC → 你跟 AI 说句话就行
```

它是**协议通道**，不是交互式命令：stdout 的每一行都会被客户端当成协议帧解析，
所以它的日志全走 stderr，你在终端里直接敲只会看到卡住不动。这是正常的。
